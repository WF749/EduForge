# 教材索引

## 这是什么

`index.json` 是从**本地教材 PDF 自动提取的目录结构**（章 / 节 / 页码），
用于回答一个问题：

> 「浮力」在人教版初中物理的哪一册、第几章、第几节、第几页？

它让生成课件时能贴上真实的教材位置，而不是让模型凭印象编一个章节号。

## 版权红线（务必遵守）

- 教材 PDF **版权归出版社**。ChinaTextbook 那类仓库自身就是 `All Rights Reserved`。
- 本目录**只存目录结构，不存任何教材正文**。
- 教材 PDF 请放在 `textbooks_local/`（已在 `.gitignore` 中，**不会入库**），
  或干脆放在仓库外的任意位置。
- **不要**把教材 PDF 提交进本仓库 —— 那会把社区项目变成我们自己的侵权风险。

## 怎么建索引

1. 取得教材 PDF（国家中小学智慧教育平台等官方公开渠道），放到任意本地目录
2. 运行：

```bash
PYTHONPATH=backend uv run --project backend python scripts/build_textbook_index.py \
    --src "你的教材目录" --out knowledge_base/textbooks/index.json
```

脚本会自动识别三种目录格式（实测覆盖）：

| 教材 | 目录格式 |
|---|---|
| 初中物理（人教版） | `第一章 机械运动 9` / `第1节 长度和时间的测量 10` |
| 小学数学（人教版） | `1 位置与方向（一）` + 换行页码 |
| 高中数学（人教 A 版） | `第六章 平面向量及其应用…………１`（全角数字 + 点线） |

## 查不到会怎样

**返回 None，并在提示里明确写"不要编造教材章节号"。**

例如「浮力」在物理八年级**下册**，本地只有上册时，系统不会编一个"第10章"，
而是降级到知识点体系组织内容。编造章节号比不提供更有害 —— 那是幻觉。
