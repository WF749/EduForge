# 教学知识库示例文件

这是一个示例知识库文件，您可以将其替换为自己的专业知识库内容。

## 文件格式说明

知识库支持以下格式的文件：
- PDF 文档
- Word 文档 (.docx)
- PowerPoint (.pptx)
- 文本文件 (.txt)
- Markdown (.md)

## 内容要求

为了获得更好的RAG检索效果，建议知识库内容包含：

1. **专业知识**：学科相关的核心概念、定义、定理
2. **教学案例**：可用于课件的案例素材
3. **教学方法**：教学设计思路、互动活动设计
4. **参考资料**：参考教材章节、权威资料摘录

## 示例内容

### 计算机科学基础

**变量与数据类型**
- 变量是存储数据的容器
- 常见数据类型：整数、浮点数、字符串、布尔值
- 强类型语言 vs 弱类型语言

**控制结构**
- 顺序结构：按语句顺序执行
- 选择结构：if/else, switch
- 循环结构：for, while, do-while

### 教学设计原则

1. **以学生为中心**：教学活动应围绕学生的学习需求设计
2. **循序渐进**：由浅入深，逐步深入
3. **理论与实践结合**：理论讲解配合实际案例
4. **互动与反馈**：鼓励学生参与，及时给予反馈
