## 服务标准

### 前台服务标准
| 项目 | 标准 |
|------|------|
| 响应时间 | 电话3声内接听 |
| 办理时间 | 常规入住≤3分钟 |
| 微笑服务 | 真诚自然 |
| 目光接触 | 适度自然 |
| 语言规范 | 使用礼貌用语 |

### 礼貌用语
- "您好，欢迎光临！"
- "请问有什么可以帮您？"
- "请稍等，我帮您查一下"
- "感谢您的入住，祝您愉快"
- "欢迎下次光临"

## 案例分析

### 案例1：超额预订处理
情景：酒店已满房，但有预订客人未到
处理步骤：
1. 确认预订状态和取消政策
2. 联系已到店客人说明情况
3. 提供替代方案（同档次酒店、升级房间等）
4. 给予适当补偿（免费接送、餐券等）
5. 做好记录和跟进

### 案例2：客人投诉房间噪音
情景：客人投诉隔壁房间太吵，影响休息
处理步骤：
1. 真诚道歉，表示理解
2. 了解具体情况
3. 实地核实
4. 提供解决方案（换房、或协调噪音源）
5. 后续跟进客人满意度
