# 预置知识库

## 它是交付内容，不是可选附件

教师第一次打开系统就能备好一节课，不该以"先上传资料"为前提。
因此本项目的知识库**随仓库自带**，位于仓库根目录 `knowledge_base/`，
由 `POST /api/rag/reindex` 全量重建，标记 `origin="seed"`。

与用户上传内容的区别：

- 用户点"清空知识库"只会清掉 `origin="upload"` 的文档，**种子语料不会被删**；
- 种子语料的增删通过改 `knowledge_base/` 下的文件再 reindex 完成；
- 检索时二者混合返回，命中片段带 `source` 与 `heading_path`，可直接溯源。

## 事实来源与核实

- **政策与文件口径**（2022 年版课程方案与课程标准、作业管理要求）核对自
  教育部公开发布的文件与新闻发布会口径，写进语料前逐条比对原文表述；
  凡官方只作原则性要求、地方解读给出具体数字的（如跨学科主题学习课时比例），
  语料中**只写原则、不写死数字**，并注明以本校课程实施方案为准。
- **教学框架**（逆向设计、5E、BOPPPS、布鲁姆修订版、等待时间）为公开公认的
  教育学成果，语料中只写可操作要点，不引具体统计数字。
- **学科知识点与常见误区**基于通行教科书体系与常见的学习困难研究，
  表述为"学生常出现的理解"，并同时给出正确概念，避免把个别现象说成普遍规律。

## 扩展语料

1. 在 `knowledge_base/` 下新建 `.md` 或 `.txt`（reindex 只认这两种扩展名）。
2. 文件名用 `序号_主题.md`，**不要有空格**（stem 就是 document_id）。
3. 结构要求：一个 `# ` 一级标题；再用 `## ` / `### ` 分节；
   单个小节正文控制在 700 字以内，让分块粒度贴合一个知识点。
4. 重建索引：`python scripts/rag_eval.py --reindex`，或在运行中的服务上
   `curl -X POST http://127.0.0.1:8005/api/rag/reindex`。
5. **同步更新评测集** `evals/rag_eval_set.jsonl`：新增文档后至少补几条
   指向它的可答题；若新增内容与某条应拒答题重叠，那条必须改成可答题。
   否则评测会留下假绿灯。
6. 跑 `python scripts/smoke_knowledge_base.py` 与 `make eval` 确认。

## 边界

- 这是**备课知识库**，不是百科全书：重点是"怎么教""学生哪儿会错"，
  不是把学科知识全量搬进来。
- 覆盖 K-12 主科（语数英物化生，兼顾道法史地）；**不含高等教育与职业教育**，
  这两块如需要应单独扩篇，不要挤占主科篇幅。
- 不收录任何个人信息、学校内部资料或需授权的内容。
